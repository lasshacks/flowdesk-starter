# Codex 첫 메시지 — 복사해서 사용

이 저장소는 팀 협업형 실시간 작업 관리 서비스 FlowDesk의 초기 설계 문서입니다.

먼저 `AGENTS.md`, `README.md`, `docs/requirements.md`, `docs/architecture.md`, `docs/tech-stack.md`, `docs/roadmap.md`, `docs/decisions.md`를 읽고, 서로 충돌하거나 미확정된 사항을 파악해주세요.

저의 목적은 단순히 서비스를 빨리 완성하는 것이 아니라 Vue 3/TypeScript와 Spring Boot/Security/JPA의 요청 처리 흐름 및 내부 원리를 이해하고, 이후 Redis/Kafka/WebSocket/WebFlux/MFA를 단계적으로 학습하는 것입니다.

**이번 턴에서는 코드를 생성하거나 의존성을 설치하지 마세요.** 다음만 제시해주세요.
1. Phase 0의 최소 구현 범위와 완료 기준
2. 로컬 환경 확인 명령어(JDK/Node/Docker 등)
3. 초기 디렉터리 및 프로젝트 생성 계획
4. Spring Boot/Gradle/Vue 버전 호환성 확인 방법
5. 지금 반드시 결정해야 할 사항만 최대 3개 질문
6. 첫 번째로 구현할 가장 작은 단위의 작업 1개

코드를 만들기 전 제 승인을 기다리세요. 이후에도 기능 단위로 설계 → 구현 → 검증 → 원리 설명 순서로 진행해주세요.
